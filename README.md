# **Git Bash**..
pwd (print working directory) = displays the path to the current folder;..
cd %directoryName% (change directory) = change directory;..
1) cd ~ = go to home directory;..
2) сd .. = go up a level;..
3) cd . = go to current directory;..
ls (list directory contents) = display directory contents;..
ls -a = display extends list with hidden files;..
touch %fileName% = creates a file in the current directory;..
mkdir %directoryName% = make directory;..
cp %sourceFile% %destFile% = copy file;..
git mv %sourceFile%​ %destFile% = Move file or directory;..
cat %fileName% (concatenate and print) = output file contents;..
rm %fileName% = remove file;..
rmdir %directoryName% = remove directory;..
rm - rf %directoryName% = delete directory with contents;..
%command1% && %command2% = execute multiple commands;..

# **GitHub**..
git init = create an empty Git repository or reinitialize an existing one;..
git status = show the working tree status;..
git add %fileName% = prepare file to saving;..
git commit -m 'commitName' = record changes to the repository;..
git log = show commit logs;..
git remote add %repName% %URL% = link remote repository to local;..
git push = update remote refs along with associated objects;..
git clone %URL% = clone a repository into a new directory;..
